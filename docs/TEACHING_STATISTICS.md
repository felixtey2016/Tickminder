# Part14 教学统计

入口沿用课程总览 / 老师课时统计。页面读取 `GET /api/teaching-statistics`，数据库完成汇总；页面不下载全部课程或提交后自行计算。此模块不提供 Quiz 成绩或财务金额。

## 月份和筛选

- 时间统一按马来西亚时间 GMT+8，以月初包含、下月初不包含的范围统计。返回所选月份、上月及连续六个月的数据。
- 支持 `month`、`teacher`、`subject`、`classroomId`。老师的课程在服务端限定 `teacher_name`，功课限定 `owner_id`；不能通过参数查看其他老师。
- 取消课程和取消课次不参与统计。历史月份的功课统计反映当前有效截止日期和最新提交状态，不是当月结束时的历史快照。

## 业务公式

| 指标 | 口径与月份归属 |
| --- | --- |
| 总排课时数 / 课次数 | 计划开始月份的 `class_sessions` 计划时长 / 数量；团体课老师时数只计一次。 |
| 已完成授课 | `teaching_status='taught'` 的共同实际授课时长，以共同实际开始月份归属；团体课只计一次。 |
| 未完成授课 | `teaching_status='pending'` 的计划时长，以计划开始月份归属，包含未来课程。已经授课但部分个人出勤待登记，不重复计入未完成授课。 |
| 可收费学生课时 | 已确认且收费的个人课程：已出席课按个人实际时长，收费的学生缺席按计划时长；前者按个人实际开始月份、后者按计划开始月份。它是学生课时，可以高于团体课老师时数。没有金额计算。 |
| 出席 / 缺席率 | 仅统计已授课、已登记的个人出勤；迟到、早退及两者兼有均算出席。分母为出席人数记录 + 缺席人数记录，排除老师缺席、未授课和待登记记录。月份采用共同实际开始时间。 |
| 待补学生课次 | 本月计划开始、未收费的学生 / 老师缺席原课；存在未取消的 `replacement_for` 课程即剔除原课，避免原课和补课重复。 |
| 待补老师时数 | 对上述待补原课按原 `session_id` 去重，再累计计划时长。明细仍按学生原课列出；核对老师时数时须按 `sessionId` 去重，不能直接相加学生明细时长。 |
| 本月排课学生 / 科目 | 所选范围内本月有计划或实际授课的不同学生 / 不同科目名称。 |
| 活跃教学老师 | 本月有实际已授课课次的不同老师，不以登录次数推测教学活跃度。 |
| 已发布功课 | 按 `starts_at` 开始发布月份归属；开始时间尚未到的功课不计。 |
| 提交 / 迟交 / 未交率 | 每份功课每位学生仅保留最新提交，排序与既有提交明细一致：`attempt DESC, submitted_at DESC, id DESC`。分母统一为已发布且当前已经到期的应交记录；有提交 / 提交晚于当前有效截止 / 无提交分别为对应分子。未来截止不算未交。 |
| 批改完成率 | 分母为已发布功课的最新已提交学生记录；该最新提交有反馈，或有明确绑定该提交且分数非空的评分历史，才进入分子。旧提交的反馈和评分不沿用，反馈及评分同时存在只计一次。 |
| 连续未交提醒 | 在当前筛选范围内，按有效截止时间倒序检查每位学生的已到期功课。最近截止须在所选月份，至少连续两份未交才提醒；遇到已提交即中止，可回溯更早月份。每页 20 位学生。 |

所有比例零分母均返回 `null`，页面显示 `—`，不显示虚构的 0%。延期截止后重新判断迟交，不使用提交行保留的旧 `late` 标记。重交不增加应交人数，也不把同一个学生算成多人。

## 权限及错误

- 管理员 / 老师须通过实时账号、集团、会话及 `statistics.view` 总门控；家长、学生拒绝访问。
- 排课、学生和科目来源要求 `lessons.view`；完成授课、收费学生课时、出勤和待补来源要求 `attendance.view`；功课来源要求 `homework.view`。
- 无来源权限的板块返回 `null`，不以 0 冒充没有业务数据；页面明确提示没有相应来源查看权限。
- 每个查询带当前授权条件，返回前再次验证；处理中撤权或登出会失败。响应为 `private, no-store`。
- 页面失败走统一错误弹窗并保留页内重试；取消请求不弹错误。权限 / 数据更新事件清除旧数据并重新读取。

## 同口径明细 API

`GET /api/teaching-statistics?view=details&metric=...&month=YYYY-MM&page=1`

支持 `teacher`、`subject`、`classroomId`、`student`、`homeworkId`。明细重新验证统计及来源权限，不依赖前端传来的角色。

- `scheduled`、`completed`、`pending`：按课次列出，一堂团体课一行。
- `chargeable`、`present`、`absent`、`makeup`：按个人学生课程列出。
- `published`：按功课列出。
- `submitted`、`late`、`missing`、`graded`：按功课及学生的去重记录列出。连续未交提醒带确切 `homeworkId` / `student` 时，以该功课截止月份定位。
- 返回 `{items,page,pages,total,pageSize:20}`；服务端先计算同条件总数，再使用 `LIMIT 20 OFFSET ...`。行提供 `sessionId` 或 `homeworkId` / `student`，供现有考勤、功课详情入口使用。
