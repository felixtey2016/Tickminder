# 资源目录（Part 12）

入口：教学资料 → 资源目录。目录与既有 PDF、课堂录影共用入口；分别按需加载。学生从班级的教学资料及文件夹查看已分配资源。

## 分类与使用

- 支持课程纲要、科目、试卷年份、Paper Code、章节、资料类型、来源搜索；每页 20 条。
- 分类读取现有学生课程菜单，不修改独立的 Quiz 分类菜单。综合官方入口可选全部科目。
- 原站链接保留来源和使用说明；不复制、托管官方试卷。文件须是原创或有明确使用许可。
- 老师可从本人已发布资料或功课 PDF 按文件名选择，明确共享至集团目录；不输入内部文件编号。
- 文件版本创建后固定。要换 PDF，新增资源；旧资料、旧功课及历史版本继续引用原文件。
- 可将同一资源分配到多个班级文件夹。分配、移动、撤回均校验当前班级、权限与版本。
- 链接可报告问题并由有权限者核实。标记失效后停止打开及新分配；封存后保留历史及文件。

## 权限

普通管理员的新资源权限默认关闭，由平台 Owner 或本集团最高管理员按查看、新建、编辑、封存、分配、分享分别授权。分配同时需要文件夹内容摆放权限。老师保留本人内容管理和所教班级范围；学生仅有当前有效班级分配。家长和学生不进入集团资源管理目录。

集团文件不跨集团公开。外链申请公开后由平台 Owner 批准；撤回、编辑或失效状态按当前权限生效，历史分配不会复活访问权。读取、写入、下载及重试都重新检查当前身份和权限。

## 官方入口

经用户确认初版 4 项，2026-10-24 核对：

- SPM：[Lembaga Peperiksaan](https://lp.moe.gov.my/)。采用可访问的官方总入口，未把无法访问的 SPM 子页标为有效。
- STPM：[MPM 课程纲要](https://portal.mpm.edu.my/stpm/sukatan-pelajaran-peperiksaan-stpm-yang-dimurnikan)。
- IGCSE：[Cambridge 官方科目](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-upper-secondary/cambridge-igcse/subjects/)。
- A-Level：[Cambridge 官方科目](https://www.cambridgeinternational.org/programmes-and-qualifications/cambridge-advanced/cambridge-international-as-and-a-levels/subjects/)。

Owner 的“加入 4 个官方入口”操作可重复使用；固定编号不会覆盖之后的手工编辑、停用或撤回。只保存原站链接，原站版权和访问条款仍适用。
