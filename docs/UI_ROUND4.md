# Quiz presentation: round 4

The Quiz page keeps its question bank, authoring, assignments and attempt records
within one existing workspace.

- Library cards group the title, subject, question count, points, difficulty and
  update date. Practice and assignment remain directly available; author tools
  expand under More actions, with deletion last.
- Filters have a distinct surface. Navigation scrolls within its own row and
  source controls allow translated text to wrap on phones.
- Assignment and attempt records separate title, status, summary and dates.
  Returning and refreshing no longer compete with a long assignment title.
- Assignment release and withdrawal controls are separate groups. Existing role
  restrictions and confirmation dialogs remain in place.
- Editor image controls, sharing controls and revision text have explicit action
  groups. Optional question classification and source fields expand on request;
  the prompt and answers stay visible. Sharing labels describe the existing
  operation more concisely.
- Ordinary controls retain at least 12px separation, including wrapped rows.
  Long names wrap inside cards and dialogs; touch targets stay at least 44px.

Question content, classifications, loading limits, timing, grading, submission,
answer release and deletion rules are unchanged. No existing quizzes are relabelled.

including real local editing, assignment targets, preview, results, incomplete
practice continuation and discard confirmation. Check runtime errors, horizontal
overflow, keyboard navigation and measured gaps between text and controls.
