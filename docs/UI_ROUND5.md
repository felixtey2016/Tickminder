# Personnel and settings: round 5

Administrator navigation groups existing destinations under Personnel & accounts
and Settings. The original student, teacher, account, group, profile, sheet-sync
and activity leaf destinations remain stable for history, shortcuts and data scopes.
Each group remembers its last view. Non-admin roles keep direct account access.

- Student and teacher directories prioritize the existing list; adding a person
  expands a compact form. Identity, academic information and actions are separate.
- Account search, status and bulk tools have explicit spacing. Identity assignment
  and account creation dialogs wrap long names without covering close controls.
- Account settings separate identity and sign-in methods from Google connection
  and password changes. Password-reset warnings remain visible when expanded.
- Group cards keep the primary manage action visible, group invitation controls
  together and expand secondary management controls. Existing classification
  lists appear before optional creation forms.
- Action groups keep 12px gaps, translated text wraps and controls remain at least
  44px tall. Narrow navigation scrolls inside its row without widening the page.

No data migration, authentication rule, account permission, academic catalogue
scope, deletion rule or spreadsheet-write behavior changes in this round.
Verify administrator history/refresh and role-restricted menus, actual populated
directories and settings on mobile/desktop, form validation, long names and gaps.
Review teacher, student and pending-account entry points as part of final acceptance.
